# 平台接入 AI Agent 前先明确准入、身份和责任

MIT Sloan 教授建议，平台在开放 Agent 接入前先决定允许哪些 Agent 进入、如何验证其身份，以及交易出错时由谁负责。例如，平台可以只允许获准的 Agent 接入，也可以接受用户自选的 Agent。
