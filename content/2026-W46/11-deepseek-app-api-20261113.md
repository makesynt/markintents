# DeepSeek 将搜索和文件输入等应用能力开放给 API 开发者

DeepSeek 宣布 `deepseek-flash` 在 Messages、Responses 和 Chat Completions API 中支持内置搜索与文件输入等能力，工具调用和上下文组装由服务端处理。
