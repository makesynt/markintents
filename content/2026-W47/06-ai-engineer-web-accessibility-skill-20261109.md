# 把网页无障碍要求写进编码 Agent 的 Skill

Jemima Abu 建议在编码 Agent 开工前加载无障碍 Skill，写清实现方式和验收条件。以简单的网页折叠区为例，优先使用原生 details 元素，并检查能否只用键盘定位到控件、展开和收起内容。
