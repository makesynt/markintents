# OpenAI 在 Codex 和 API 推出 GPT-6.2 Astra 与 Sol

GPT-6.2 Astra 和 Sol 已向符合条件的 Codex 用户开放，两个模型也可通过 API 调用。OpenAI 将 Astra 定位于复杂推理和编程任务，将 Sol 定位于日常编程和 Agent 工作流。
